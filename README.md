I usually use a user-friendly approach to designing software, however due to the nature of this assignment and who would be looking at the back end. As a result I adopted a very few comment approach. Since the only person expected to look at this code is someone who understands the basics of coding already, I used comments less as an information method and more as a navigational tool.
Furthermore, the approach to programming was to get it working first and then get it working properly. Often would have a placeholder code that needed to either be removed or updated later but fit the role of being there.
Iteration took centre stage in my design process as I would come back to the program every day modify it slightly than come back to it another day. This meant that I kept several out of date iterations of my code which I would sometimes go back to when needing to retrieve a functional piece of code that is not there in the current version.
